# PerAppVolume 修订包

## 替换
将本目录中的文件覆盖到仓库根目录，保留目录结构，然后提交到 main 并运行 GitHub Actions。

## 本次修订
- 修正 PVMuted 拼写及函数调用问题。
- 主界面加入关闭按钮。
- 超音量开关切换时更新主音量及声道滑块上限。
- 保留原有 Theos Makefile、DSP 源码、control 和 Actions 工作流。

## 重要限制
此版本不是全局音频驱动。AVAudioPlayer/AVPlayer 的 volume 属性不能实现可靠的 100% 以上增益；左右声道滑块目前没有接入实际的采样处理链路。后台不冲突播放开关也只是设置状态，不能保证阻止其他应用中断。
双指手势与悬浮球受注入目标应用的窗口/场景生命周期影响，需在目标 iPad 实测。窗口布局及系统缩放也需要实机验证。
本包未在 Theos/iOS SDK 下完成编译验证，Actions 成功前不要视为可安装版本。
仅在有权修改和测试的应用中使用。
